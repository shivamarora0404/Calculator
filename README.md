# 🎨 Super Cool Fun Calculator

![Python](https://img.shields.io/badge/python-3.7+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)

A colorful, interactive terminal-based calculator with multiple modes and awesome animations! 🚀

## ✨ Features

- **🎨 Colorful Interface**: Beautiful ASCII art and color-coded output
- **➕ Basic Calculator**: Standard arithmetic operations (+, -, *, /, ^, %)
- **🔬 Scientific Mode**: Trigonometric functions, logarithms, square root, and factorial
- **🔄 Conversion Mode**: Temperature, distance, and weight conversions
- **💡 Math Fun Facts**: Learn interesting mathematical trivia
- **⚡ Animations**: Typing effects and loading animations for enhanced user experience
- **🎯 User-Friendly**: Easy-to-navigate menu system with error handling

## 📋 Requirements

- Python 3.7 or higher
- No external libraries needed (uses only Python standard library)

## 🎮 Usage

Run the calculator and choose from the available modes:

### Basic Calculator Mode
Perform standard arithmetic operations:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Power (^)
- Modulo (%)

### Scientific Mode
Access advanced mathematical functions:
- sin(x), cos(x), tan(x)
- sqrt(x)
- log(x), ln(x)
- factorial(x)

### Conversion Mode
Convert between different units:
- Temperature (Celsius ↔ Fahrenheit)
- Distance (Kilometers ↔ Miles)
- Weight (Kilograms ↔ Pounds)

### Math Fun Facts
Learn interesting mathematical trivia and facts!
